# Lottery Game 品牌标志

品牌全称为 **Lottery Game**，简称 **LG**。主标由 AI 生成的 LG 翡翠绿/金色徽记和矢量字标组合；徽记使用 WebP，文字使用 SVG，品牌字样因此不会被图像生成模型写错。

徽记提示词：以准确可读的 `LG` 大写字母组成紧凑徽记；翡翠绿、暖象牙白和精致金色；简洁、清晰，缩小到 32px 仍可识别；透明背景；不添加额外文字、人物、卡牌、金币、老虎机、骰子或背景。

美术通过 Codex 内置 OpenAI 图像生成工具创作。图像端实际模型标识未由工具返回，因此不虚构模型 ID；原始图像保留于 candidates，线上使用 640×640、56 KB 的透明 WebP。横版和竖版字标使用 SVG，避免额外位图请求。
