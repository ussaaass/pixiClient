# 十三张专属视觉风格

本风格仅用于十三张的子厅、牌桌和游戏内牌面/特效。它属于 Gameing Hall 品牌下的独立游戏视觉包，与外部横向多游戏大厅有意区分。

- 外部大厅负责展示多个游戏，明亮、友好、轻量；十三张子厅与牌桌表现专注的纸牌策略氛围，不复用外部大厅的大厅拱门、通用徽记和大面积明亮留白构图。
- 统一材质基调：精致的风格化 3D 休闲手游插画，圆润但更克制，深翡翠绿桌呢、墨绿色阴影、暖象牙白牌面、少量抛光暖金镶边；柔和暖光与清晰轮廓，不做照片级真实赌场。
- 当前子厅试样 `assets/candidates/shisanshui-subhall-background/aab473a3-ad3b-4784-8474-df7c2a50458b/source.webp` 用作游戏内风格参考：暗翡翠桌呢、圆润金边、边缘灯光。它不是外部大厅背景，也不复制其满屏牌桌布局到所有资源。
- 主题线索限于十三张纸牌、扇形牌组、三道牌列、桌呢和牌背几何纹样。不要生成筹码、轮盘、骰子、现金或任何不属于本游戏的道具。
- 游戏背景优先保证卡牌与交互区对比清晰；不要把玩家、文字、点数、花色、分数、按钮或具体牌局结果烘焙进背景/牌背/边框。
- 外部品牌锚点只借用精致立体的渲染质量。游戏内参考图优先于外部大厅的具体构图和亮度。
- 所有文字、点数和花色由游戏代码绘制；角色插画不得画进具体点数或花色标识。

视觉参考图应按素材规格传入 OpenAI 图像请求，并明确是风格参考还是游戏内容参考。每个输出仍需单独审核；参考图可以提高一致性，不能保证模型严格复刻。
