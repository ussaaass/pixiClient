# 临时电子音占位素材

由内置 Node.js 合成脚本生成，不调用 AI 服务或外部素材。所有文件都是临时占位音，不代表最终美术/声音风格。

- 36 个音效 ID 与 docs/07_assets/游戏音效设计与资源清单.md 对齐。
- WAV 为 48 kHz、单声道、16-bit PCM；WebM 为 32 kbps Opus，供快速集成测试。
- 重新生成：在仓库根目录运行 node tools/audio-placeholders/generate.mjs（需要本机 ffmpeg 支持 libopus）。
- 最终 AI 音效制作完成后按相同 ID 替换，并更新清单/哈希；不要把占位音当成最终发布素材。
