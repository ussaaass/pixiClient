# PC 大厅卡片问题与修正计划

状态：PC 全宽卡带、9:16 专用竖版背景、首卡吸附、C 位动效和在线状态表现已实施；Chrome Headless 桌面/Mobile 视口几何验收通过。原生 AVIF 帧播放还需要 Safari/Firefox 真机复核。

## 1. 当前只处理的两个问题

### 1.1 PC 游戏卡带宽度与卡片宽高比

PC 游戏卡带当前受 `.lobby-shell { max-width: 1180px }` 限制，导致卡带没有铺满浏览器 viewport。卡片的实际宽高也不符合目标比例。目标是让 `.game-row` 的可视滚动区域延展至全 viewport 宽度，同时让 PC 卡片采用 **9:16 竖向比例**。

已将[PC 大厅游戏卡片与动效背景 SDD](../06_ux/PC大厅游戏卡片与动效背景SDD.md)校准为 9:16 桌面竖卡，重新生成桌面专用竖版背景并派生静态海报和镜头运动 AVIF。背景铺满卡片并按比例裁切，不拉伸。Mobile 沿用自己的宽幅背景与大厅布局。

计划约束：

- 只让 PC `.game-row` 全宽；顶部栏及其他页面内容可继续使用适当的阅读宽度。
- 卡带左右保留响应式安全边距；滚动区域自身可横向溢出，页面不能出现非预期横向滚动。开头只加入将第四张十三张放到 C 位所需的自适应留白，宽度不足则留白为零；首卡靠左吸附，不会成为初始 C 位。尾端保留居中最后一张的滚动余量。
- 卡片宽高由 9:16 比例锁定并设置合理尺寸边界。默认焦点仍为第四张十三张；首卡不允许因居中留白变成初始 C 位。
- 现有图标、标题与简介继续使用；本次不额外加新字段或重排游戏信息。
- PC 背景使用专用 9:16 竖图铺满卡片；Mobile 继续使用既有横图 source，不改移动端布局和背景。
- 在线状态文案统一为“当前在线”；绿点加入低幅呼吸动画，尊重 `prefers-reduced-motion`。

### 1.2 AVIF 动效没有播放

当前目录中的 `active.avif` 是 24 帧、8 fps、3 秒循环的动画资源，`poster.avif` 与 `poster.webp` 是静态回退。卡片静止并成为焦点后请求对应的 `active.avif`；桌面额外叠加低幅度 CSS 镜头漂移，确保动效反馈可见。非焦点卡显示静态 poster。鼠标悬停可临时激活对应卡，移开后恢复中心卡动效。

实现中为 `<picture>` 设置变体 key，在焦点变化时重建节点，要求浏览器重新选择 AVIF source。libavif `avifdec --info` 可确认活动资源包含 24 帧，逐帧导出也确认帧画面不同；当前 HeadlessChrome 连续 canvas 取样只显示首帧。桌面因此增加只作用于焦点卡片的 CSS 镜头漂移，作为浏览器原生帧播放之外的可见动态反馈，并遵循 `prefers-reduced-motion`。AVIF 不可用或解码/下载失败时仍回到静态 poster。

大厅卡带随一级页面路由切换会卸载并重新创建。若只在 App 首次挂载时给 `.game-row` 绑定 `scroll` 监听，钱包/社区返回大厅后，新轨道不会再更新 C 位，于是十三张之外的卡片无法随滚动切换动效。已在大厅页恢复时重绑定监听并重新对齐默认 C 位；回归测试覆盖钱包返回后滚动切换到麻将胡了。

## 3. 验收 Checklist

- ✅ PC 卡片 SDD 的宽高比已从 16:9 统一改为 9:16，且明确不改变 Mobile 卡片布局。
- ✅ PC `.game-row` 使用全 viewport 宽度；根据第四张卡的初始居中位置计算开头留白，首卡左侧吸附且不成为 C 位，尾端保留滚动余量。
- ✅ PC 卡片外框与新背景均为 9:16；Mobile 继续使用原有宽幅资源。
- ✅ 默认 C 位为第四张十三张；首端没有将跳高高推至 C 位的空白弹性项。
- ✅ 在线状态显示“当前在线”；连接绿点增加呼吸动画，并支持 reduced-motion。
- ⬜ 焦点卡的 `active.avif` 原生帧在 Safari/Firefox 中连续播放；Chrome Headless 中资源 URL 正确且图片可解码，但连续采样未看到图像帧变化。
- ✅ 鼠标进入其它游戏卡时激活动效资源，离开后恢复当前中心卡；静态海报节点保持不变，Vitest 验证动效覆盖层的加载态与挂载/卸载。
- ✅ 从钱包返回大厅时为新挂载的游戏卡带重新绑定 scroll 监听；桌面浏览器及 Vitest 验证滚动后其它 C 位可切换到 active 资源。
- ✅ 卡片焦点切换时静态海报保持常驻，active AVIF 覆盖层加载完成后淡入，避免整张背景替换造成闪烁；非焦点卡不请求动图。
- ✅ 焦点卡增加低幅度 CSS 镜头漂移；HeadlessChrome 中 500ms 前后的 computed transform 不同。该效果在 `prefers-reduced-motion: reduce` 下关闭。
- ⬜ AVIF 下载或解码失败时浏览器仍显示 WebP poster；需要实际浏览器覆盖确认。
- ✅ HeadlessChrome 检查 1280×720、1440×900、1920×1080、2560×1080；页面 `scrollWidth/clientWidth` 与 `scrollHeight/clientHeight` 均相等，`.game-row` 从 x=0 铺满 viewport，卡片为 9:16。
- ✅ HeadlessChrome 回归检查 390×844 Mobile 大厅：页面无横/纵向溢出，横向卡片布局保持不变。
- ⬜ 在真实浏览器延时取样确认动画帧变化；仅检查 AVIF 文件包含多帧不能代替播放验收。
