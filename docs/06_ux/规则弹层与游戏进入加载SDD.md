# 规则弹层与游戏进入加载 SDD

版本：1.0（首版施工）  
范围：手机游戏卡片中的规则弹层过渡，以及进入 Pixi 牌桌时的加载、慢速等待、取消和失败恢复。大厅 HTML 启动页加载另见[启动页与加载进度设计 SDD](./启动页与加载进度设计SDD.md)。

## 1. 目标与现状

手机游戏卡片要保持紧凑：封面 Logo 与标题同行，标题旁放规则入口，简介和难度入口接续其下。打开规则时，用户应看出一张面板从底部抽出，而不是内容突然出现。选择难度后，H5 会动态导入十三张 Pixi 模块、初始化渲染器并准备首局；在此期间要有明确、稳定的等待反馈。

Pixi 模块动态导入不提供浏览器原生的逐字节进度回调，`Application.init()` 也没有本项目可用的总进度值。游戏加载层因此显示真实阶段、有根据的已等待时间和持续活动的非定量进度轨道，不伪造百分比。大厅首次启动页的估算百分比仅描述启动阶段，不能复用于游戏进入进度。

## 2. 规则弹层交互

手机卡片标题旁显示 44 px 以上热区的问号图标和“规则”字样。点击后打开底部抽屉，内容为十三张完整规则摘要：人数/牌数、3/5/5 分墩、倒道、牌型顺序、逐墩计分及按厅配置生效的特殊奖励。关闭按钮和遮罩空白处可关闭；关闭后仍停留在大厅卡片原位置，选档状态不受影响。

动效时间线：

| 阶段 | 动效 |
| --- | --- |
| 打开 0–220 ms | 背景遮罩淡入；抽屉从屏幕底部 `translateY(100%)` 上移到停靠位置，使用 ease-out 曲线 |
| 停靠 | 抽屉贴住视口底部并处理 iOS 安全区；正文过长时只在抽屉内滚动 |
| 关闭 0–200 ms | 抽屉向下退出，遮罩同步淡出；结束后销毁弹层 |
| 桌面 | 居中规则面板轻微上移并淡入，不使用手机尺寸的全屏滑动 |

`prefers-reduced-motion: reduce` 时将上述过渡缩短至近乎即时。键盘焦点圈保持可见；后续补完焦点进入/归还、Tab 限制与 Esc 关闭验收。

## 3. 进入牌桌的状态与页面

```text
用户点击一个难度
  → 记录来源页和练习档
  → 全屏牌桌加载层（保留背景牌桌底色）
  → 动态导入十三张客户端包
  → 初始化 Pixi Application / Renderer
  → 首帧与演示手牌准备完成
  → 加载层淡出，进入可交互牌桌

任一阶段失败 → 错误页（重试 / 返回上一页）
等待超过 12 秒 → 显示仍在处理的说明与“返回上一页”操作
```

手机从大厅难度直达练习，取消/退出返回大厅。桌面从子厅选择难度，取消/退出返回子厅。加载层不覆盖品牌大厅启动页；它由 Pixi 入口所在的练习页承载，确保下载 JS 时已有可见状态。

## 4. 加载层布局和文案

```text
┌────────────────────── 全屏牌桌底色 ──────────────────────┐
│                                                          │
│                    ◉ 旋转环                               │
│                 正在载入牌桌程序                           │
│                                                          │
│       [载入程序] ─ [初始化画面] ─ [准备牌局]               │
│       ━━━━━━ 流动扫光（不表示精确百分比）                  │
│                                                          │
│       已等待 4 秒 · 首次进入需要准备牌桌资源               │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- 当前步骤使用暖金高亮；已完成步骤转为柔和绿色；未开始步骤降低对比度但仍可读。
- 每秒更新实际等待时间。超过 12 秒显示“加载时间比平时长，你可以继续等待，或返回上一页。”并展示返回操作，不自动刷新。
- 调用失败显示错误信息和“重试加载”“返回上一页”。重试沿用当前难度，重新走模块导入和渲染器初始化，不改变练习数据或钱包。
- 加载覆盖层淡入/淡出约 200 ms；扫光与旋转环循环运动。减少动态效果偏好开启时停用循环动画，仍保留阶段文字和已等待时间。
- 页面离开时停止等待计时器。异步初始化若在退出后才完成，必须立即 dispose 新建的 Pixi session，不能把渲染器挂在脱离 DOM 的容器上。
- 游戏准备完成后延迟约一帧淡出，避免“刚出现即消失”的闪屏；牌桌首帧必须先可见再解除覆盖。

## 5. 实现边界与弱网行为

- 继续使用 Vue `Transition`、CSS transform/opacity 和 Pixi 自有动态导入，不增加动画/加载依赖。
- 阶段只在真实边界切换：动态导入开始、模块可用并开始 Pixi 初始化、`mountLocalGame` 返回且容器仍有效。扫光只表达“当前仍在工作”，不表达下载字节数。
- 等候计时不依赖服务端 Socket 或健康检查；本地练习在服务端离线时仍可进入。后续切换真实匹配时，必须由服务器准入确认后再分配房间，并采用对应的联机加载/超时政策。
- 退出期间还在等待的动态导入允许自然完成，但不得挂载到已离开的页面；Pixi 初始化返回 session 后先检查目标 DOM/当前页面，若已取消就立即 dispose。
- 后续如资源加载器提供总字节数与完成字节数，可将轨道替换为真实进度；只有阶段估算时不显示百分比。

## 6. 闭环验收 Checklist

- ✅ 手机“规则”入口打开由底部滑入的规则抽屉；遮罩淡入、关闭反向下滑；桌面采用轻量居中面板过渡。
- ✅ 练习入口立即显示加载层，并按模块导入、Pixi 初始化、牌局就绪切换步骤。
- ✅ 加载扫光不显示虚假的百分比，计时展示真实已等待秒数。
- ✅ 超过 12 秒提供返回操作；初始化失败提供重试与返回；重试保留当前练习档。
- ✅ 取消后返回触发来源页；异步初始化晚到时 dispose 已创建 session，等待计时器会停止。
- ✅ `prefers-reduced-motion` 全局规则降低弹层与加载层动效。
- ✅ 弹层打开后焦点进入关闭按钮；Tab 在弹层内循环，Escape 关闭并将焦点还给原触发项；大厅背景设为 `inert`；弹层期间固定 body 并锁定 `html`/`body` 滚动，关闭/卸载恢复原样式与滚动位置（Vitest + headless Chrome 验证）。
- ✅ 弹层关闭控件触控区域为 44×44 px，且通过调整控件外框位置保持关闭图标的视觉中心不变；320×568、390×844 与 1280×800 浏览器几何无非预期根文档溢出。
- ⬜ 在低速/高延迟设备实测首屏加载遮罩绘制、等待状态持续时间和错误重试手感。
- ⬜ 真机 Safari/Chrome 验收抽屉与安全区、滚动锁定和读屏播报。
- ⬜ 真实联机房间接入时补充准入等待、房间分配、资源下载超时和服务端可恢复状态的专项加载 SDD。
