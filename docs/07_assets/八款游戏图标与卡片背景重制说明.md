# 八款游戏图标与卡片背景重制说明

日期：2026-10-18。版本：1.2。范围：跳高高、夺宝奇侠、麻将胡了、十三张、麻将胡了 2、捕鱼、赏金女王、3快的大厅游戏图标、PC 竖版/Mobile 卡片背景和焦点卡动效。

## 1. 目标与结论

此前一批宽幅卡片背景与部分游戏题材关联不够准确，因此本批重新整理公开题材线索、改写创作提示词，并重制 8 张背景。另为每款游戏分别制作一张透明图标，解决“麻将胡了，即将开放”仍使用通用牌类图标的问题。PC 已使用统一风格的 9:16 竖版背景。Mobile 新增两组 7 张竖版静态候选：第一组位于 `assets/candidates/mobile-game-cards-v1/`，第二组由 OpenAI API 生成，位于 `assets/candidates/mobile-game-cards-openai-v1/`；两组都待审核后再决定接入。赏金女王按要求保留现有素材。图标继续由 PC 与 Mobile 共用。

本次是原创主题插画，不复制参考站点的 Logo、角色、截图、UI 或具体素材。官方游戏页面仅用于理解玩法气质和辨识线索。常规游戏名、状态、玩法介绍均由 H5 文本绘制，AI 图片不负责生成可读文字；麻将胡了 2 的中心“胡了！”是代码排版叠加，确保字形准确。十三张的扑克牌使用传统牌面语汇，不能用自创卡通角色取代 J/Q/K。

### PC 竖版背景统一提示词

八张桌面背景均单独生成，使用相同风格约束和题材锚点：`竖屏 9:16 游戏卡片背景，构图适合从上到下完整铺满窄长卡片，单一主题主体集中于画面上半部中间，卡片下半部保留暗色、低细节区域以叠加图标、标题和按钮；精致圆润 3D 卡通手游插画，统一材质表现、柔和体积光、清晰轮廓、细节丰富但背景简洁。` 每张只替换对应游戏的视觉主题描述，沿用上表负面约束。十三张坚持传统扑克牌面，不要求模型造新人物牌面。该批 PC 母图为 941×1672 PNG；移动版宽幅母图保持不变。

统一负面约束：`不要文字、字母、数字、Logo、水印、边框UI、赔率、真实货币、支付商标、具体中奖信息、重复主体、错乱扑克牌花色或麻将字符、照片写实人物、抄袭已有游戏画面。` 图像模型对牌面/汉字仍可能生成错误细节；需要准确表达的字符和数字必须由 H5/Pixi 绘制。

## 5. Mobile 与 PC 验收清单

- ✅ 八款游戏分别有专属 512×512 图标、静态主题背景与循环背景。
- ✅ PC 与 Mobile 都由同一个 `assetKey` 映射加载专属图标；十三张 Mobile 标题行显示十三张图标，其他七张移动卡显示对应图标。
- ✅ 每款游戏卡的静态背景都使用本游戏主题，不把旧版十三张图标或背景用作其他游戏占位。
- ✅ Mobile 继续使用原宽幅背景，不加载 PC 9:16 新图；图标保持比例。
- ⬜ 审核 `assets/candidates/mobile-game-cards-v1/` 内 7 张静态候选；赏金女王保持现有素材，不生成替换图。
- ⬜ 并排审核 OpenAI API 第二版 `assets/candidates/mobile-game-cards-openai-v1/` 与第一版；选中的静态母图获批前不接入生产资源。
- ✅ 按用户选择，以 OpenAI 第二版静态候选为输入，通过 Kling v3 生成七款 Mobile 动效并派生 537×960、40 帧、8 fps 无限循环 AVIF；提示词与请求元数据记入 Kling job 台账。
- ⬜ 审核第二版静态图与对应 Kling 动效；审核通过后再将选中素材优化为 Mobile 正式资源并接入，候选 AVIF 当前没有替换线上资源。
- ⚠️ 抽帧视觉验收发现：麻将胡了 2 第一版麻将牌为空白；捕鱼第一版用了锦鲤；3快第一版号码球无号码；十三张两版都出现卡牌重绘/模糊；跳高高两版都没有清楚表现迪斯科球旋转。不得把“生成成功”视为视觉验收通过。

- ✅ 麻将胡了 2 OpenAI v6 静态候选已按“四条腿、四只爪都清楚可见”重构；每只爪有几根趾不作为验收条件。
