# 八款游戏图标与卡片背景重制说明

日期：2026-10-11。版本：1.1。范围：跳高高、夺宝奇侠、麻将胡了、十三张、麻将胡了 2、捕鱼、赏金女王、3快的大厅游戏图标、PC 竖版/Mobile 宽版卡片背景和焦点卡动效。

## 1. 目标与结论

此前一批宽幅卡片背景与部分游戏题材关联不够准确，因此本批重新整理公开题材线索、改写创作提示词，并重制 8 张背景。另为每款游戏分别制作一张透明图标，解决“麻将胡了，即将开放”仍使用通用牌类图标的问题。当前再为 PC 卡片生成一组统一风格的 9:16 竖版背景并派生更明显的 AVIF 镜头运动；Mobile 仍加载原宽幅版本。图标继续由 PC 与 Mobile 共用。

本次是原创主题插画，不复制参考站点的 Logo、角色、截图、UI 或具体素材。官方游戏页面仅用于理解玩法气质和辨识线索。游戏名、状态、玩法介绍均由 H5 文本绘制，AI 图片不负责生成可读文字。十三张的扑克牌使用传统牌面语汇，不能用自创卡通角色取代 J/Q/K。

## 3. 可复用提示词规格

### PC 竖版背景统一提示词

八张桌面背景均单独生成，使用相同风格约束和题材锚点：`竖屏 9:16 游戏卡片背景，构图适合从上到下完整铺满窄长卡片，单一主题主体集中于画面上半部中间，卡片下半部保留暗色、低细节区域以叠加图标、标题和按钮；精致圆润 3D 卡通手游插画，统一材质表现、柔和体积光、清晰轮廓、细节丰富但背景简洁。` 每张只替换对应游戏的视觉主题描述，沿用上表负面约束。十三张坚持传统扑克牌面，不要求模型造新人物牌面。该批 PC 母图为 941×1672 PNG；移动版宽幅母图保持不变。

统一负面约束：`不要文字、字母、数字、Logo、水印、边框UI、赔率、真实货币、支付商标、具体中奖信息、重复主体、错乱扑克牌花色或麻将字符、照片写实人物、抄袭已有游戏画面。` 图像模型对牌面/汉字仍可能生成错误细节；需要准确表达的字符和数字必须由 H5/Pixi 绘制。

| Mobile/旧版静态卡片背景 | `apps/web/public/assets/game-cards/{assetKey}/poster.avif` | 保留 1536×864 横图，供 Mobile 与桌面资源回退。 |
| PC 竖版静态海报 | `apps/web/public/assets/game-cards/{assetKey}/portrait/poster.avif` 和 `poster.webp` | 540×960，同一构图；桌面通过 `<picture media>` 选择并按可见范围加载。 |
| PC 焦点卡循环背景 | `apps/web/public/assets/game-cards/{assetKey}/portrait/active.avif` | 432×768、24 帧、8 fps、3 秒循环；从本轮竖版母图通过缩放和横纵位移派生更明显的镜头推近，不是 AI 视频生成。 |

图标与背景通过 `assetKey` 配对：`slot5 → jump-high-high`、`slot3 → treasure-hero`，其余为 `mahjong-hule`、`shisanshui`、`mahjong-hule-2`、`fishing`、`bounty-queen`、`three-fast`。这两个别名是稳定目录 ID 与美术资产名不同的显式映射。PC/Mobile 共用图标；桌面使用新生成的竖版背景，Mobile 使用既有宽幅背景。十三张 Mobile 首卡将图标放在标题行；其它卡片采用图标列+说明列。背景 `object-fit: cover`，方形图标 `object-fit: contain`，不得把 1:1 图标拉伸为横幅。

生成工具只提供图像结果和保存路径，没有向本执行端返回可核验的图像模型 API ID、供应商请求 ID 或单张价格。本台账据实标注“工具未暴露”；不得将主模型名称臆造为 Images API 模型 ID，也不在此推算费用。项目后续接入正式素材生成 API 时，应将明确的图像模型 ID、请求 ID、seed（若接口支持）、提示词版本和实际账单写入生成台账。

## 5. Mobile 与 PC 验收清单

- ✅ 八款游戏分别有专属 512×512 图标、静态主题背景与循环背景。
- ✅ PC 与 Mobile 都由同一个 `assetKey` 映射加载专属图标；十三张 Mobile 标题行显示十三张图标，其他七张移动卡显示对应图标。
- ✅ 每款游戏卡的静态背景都使用本游戏主题，不把旧版十三张图标或背景用作其他游戏占位。
- ✅ Mobile 继续使用原宽幅背景，不加载 PC 9:16 新图；图标保持比例。
- ✅ 游戏名称、开放状态和玩法文案以 DOM 文本绘制，不依赖 AI 文字；未开放状态仍展示游戏识别图和详情。
- ✅ 8 段 AVIF 动图验证为 24 帧；焦点/鼠标悬停卡片切换动效，离开悬停后恢复焦点卡。
- ⬜ 真机检查 320、360、390、430 CSS px 宽及横屏手机的标题换行、图标大小、背景焦点和卡片高度；确认页面无意外横向溢出。
- ⬜ 桌面检查 1280×800、1440×900 与窄桌面宽度；验证卡带高度、中央焦点和裁切。
- ⬜ 在 Safari、Chromium、Firefox 桌面/移动端实测 AVIF 动图与 WebP 回退、流量和解码开销。
- ⬜ 由产品审核本批图像风格、题材、扑克牌准确性及麻将“胡”字质量；审核完成后更新素材批准状态。
- ✅ 为 PC 重生成八张同系列 9:16 竖版背景，并派生静态 AVIF/WebP 与加强推近/漂移的 24 帧循环 AVIF；不替换 Mobile 宽幅素材。
