# 项目文档

当前阶段：浏览器大厅/Admin 前端和最小 Koa 健康检查服务已运行；玩家身份与业务 API 尚未闭环。Admin UI 使用 Vue 3 + TypeScript + Vite + Element Plus，monorepo 使用 pnpm workspace。用户约束优先；目录以结构规划为准，下载实现以网络设计为准。

数据库权威规范见 [数据库设计规范与 Sequelize](./05_data/数据库设计规范与Sequelize方案.md)，统一 id、状态、三个 DATETIME、引用命名、注释与 ORM，覆盖旧表名/字段草案。系统资产来源、渠道费、兑换提现及外部对账见 [系统账户与资产记账设计](./04_domains/系统账户与资产记账设计.md)。

最新业务确认见 [业务配置与账号代理细化](./04_domains/业务配置与账号代理细化.md)：game_config/system_config、5% 转账手续费、注册赠币 1000、提现费 5%、二维码/邀请链接 2 年有效期、客服文件保留 2 年、玩法配置开关、同表用户与 role_type、邀请返佣、账号绑定恢复、浏览器优先及卡通美术。

最新邀请与返佣补充见 [邀请归因、返佣与数据规范](./04_domains/邀请归因返佣与数据规范.md)：IP 首次绑定、reward_type、本人计入五级、冻结奖励和全表基础字段。该文件覆盖较早的层级计数草案。充值购买金币、返点入余额与兑换后提现见 [双资产充值兑换与提现](./04_domains/双资产充值兑换与提现.md)。

客损模式最终边界见 [代理客损模式边界](./04_domains/累计客损结算口径.md)：客损及返佣由代理线下结算；平台限制客损用户的资产入口，并允许其当前祖先链供币。登录确定采用 JWT，详见 [JWT 登录与会话设计](./04_domains/JWT登录与会话设计.md)。

最新支付/流水决定见 [支付渠道、流水要求与直连归因](./04_domains/支付渠道流水要求与直连归因.md)：人民币余额、默认 1:10、代理支付方式、TRON 自建 USDT、统一金币赠币流水、平台充值返点、1000 枚整数倍及身份三选一。客损模式由代理线下结算。
